# Grammars

Prebuilt tree-sitter grammars and their tags queries, copied unchanged from the npm packages below (MIT, licenses beside each). Contextualise loads them with `web-tree-sitter` 0.25.10 to list the functions, classes, methods, and types in a repository.

| Folder | Package |
| --- | --- |
| `javascript/` | `tree-sitter-javascript` 0.25.0 |
| `typescript/` | `tree-sitter-typescript` 0.23.2 (TypeScript and TSX; its tags query adds to the JavaScript one) |
| `python/` | `tree-sitter-python` 0.25.0 |
| `go/` | `tree-sitter-go` 0.25.0 |
